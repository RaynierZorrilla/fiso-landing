# FISO – Finance Solution 🚀

**FISO** (Finance Solution) es una plataforma digital inteligente y educativa enfocada en la gestión financiera personal y de microempresas. Este repositorio contiene el **Landing Page** oficial del proyecto, diseñado para presentar las funcionalidades clave, visión y beneficios de FISO al público.


## Características principales

- **Secciones:**
  - Inicio (Hero)
  - Características/Servicios
  - Estadísticas
  - Sobre Nosotros (Misión y Visión)
  - Contacto (formulario e información)
  - Footer con enlaces y redes
- **Diseño responsivo** para móviles y escritorio
- **Animaciones y transiciones** modernas
- **Formulario de contacto** (sin backend)
- **Estadísticas y testimonios visuales**
- **Navegación sticky** y menú móvil

## Tecnologías utilizadas

- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [TailwindCSS](https://tailwindcss.com/)
- [Lucide React Icons](https://lucide.dev/icons/)

## Instalación y uso

1. **Clona el repositorio:**
   ```bash
   git clone <url-del-repo>
   cd Fiso-Landing
   ```
2. **Instala las dependencias:**
   ```bash
   npm install
   ```
3. **Inicia el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   El proyecto estará disponible en `http://localhost:5173` (o el puerto que indique la terminal).

4. **Compila para producción:**
   ```bash
   npm run build
   ```

5. **Previsualiza la build de producción:**
   ```bash
   npm run preview
   ```

## Estructura del proyecto

- `src/App.tsx`: Componente principal con todas las secciones de la landing.
- `src/main.tsx`: Punto de entrada de la app.
- `src/index.css`: Estilos base con TailwindCSS.
- `index.html`: HTML principal.

## Scripts disponibles

- `npm run dev`: Inicia el servidor de desarrollo.
- `npm run build`: Compila la app para producción.
- `npm run preview`: Previsualiza la build de producción.
- `npm run lint`: Ejecuta el linter ESLint.
